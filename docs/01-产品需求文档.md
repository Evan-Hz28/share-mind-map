# 共享思维导图平台产品需求文档

版本：V1.1  
状态：首版开发基线  
更新日期：2026-09-16

## 1. 产品定位

本平台是面向公司内部开发、产品、测试等团队的 Web 测试用例文档管理平台，用于集中存储、查看、编辑、搜索和共享 XMind 文档。Reviews Optimization 只是可被平台容纳的一份示例文档，不是平台的专属业务定位。

首版优先解决“共享查看”和“受控协作”。同一时间只允许一个浏览器会话编辑文档，其他成员只读并实时接收已保存内容。首版不实现 Google Docs 式多人同时编辑，但数据模型和通信边界需要为后续 CRDT/OT 升级预留空间。

## 2. 首版目标

- 由管理员预创建的公司成员能够使用本地账号密码登录唯一组织和默认工作空间。
- 云端展示效果与指定的本地 XMind 文档保持较高一致性。
- 支持文件夹、文档、导入、编辑、搜索、历史版本、回收站和导出等完整流程。
- 权限、编辑锁、保存冲突、断网和删除恢复等场景不得静默丢失用户内容。
- 建立可扩展的标准文档模型，不让业务数据绑定具体 XMind 解析器或画布组件。

## 3. 首版不做

- 多组织、多工作空间。
- Lark OAuth、Lark 组织架构或群组同步。
- 文件夹级、文件级权限和组织外分享。
- 多人同时写入、离线编辑。
- 多级文件夹。
- 测试执行状态、测试轮次、通过率和结果统计。
- 开放注册、邮件验证、用户自助找回密码和其他身份源登录。
- 对外开放 API。
- 完整移动端编辑和深色模式。
- 通用附件、GIF、SVG 在线编辑。
- 对所有 XMind 私有扩展和复杂自由布局做 100% 还原承诺。

## 4. 用户与权限

| 角色 | 获取方式 | 主要能力 |
|---|---|---|
| 只读成员 | 管理员创建账号时默认获得 | 浏览、搜索、查看、导出 |
| 编辑者 | 主动申请并由管理员审批 | 只读能力，以及导入、编辑、创建、重命名、移动、删除、恢复 |
| 管理员 | 首个管理员由系统维护者通过一次性初始化命令创建 | 编辑者能力，以及账号创建/重置/停用、审批、成员管理、审计、清空回收站、强制释放锁、系统状态管理 |
| 系统维护者 | 运维职责，不是普通业务角色 | 维护部署配置、组织初始化、配额、保留策略、密钥、备份和发布 |

权限规则：

- 管理员创建的新成员默认拥有整个工作空间的阅读权限。
- 编辑权限是工作空间级别，获批后可编辑全部文档。
- 申请只记录申请人和申请时间，不强制填写原因，也不设置有效期。
- 申请状态包括：待审批、已通过、已拒绝。
- 管理员可以撤销编辑权限，撤销立即生效。
- 权限撤销前已保存内容正常保留；未保存内容必须提示处理并支持临时保留、复制或导出草稿，不得静默丢弃。
- 所有后端接口和实时事件必须再次校验权限，前端隐藏按钮不能代替服务端鉴权。

## 5. 信息架构

```text
组织
└── 默认工作空间
    ├── 用例库
    │   ├── 一级文件夹
    │   └── 未归档文档
    ├── 回收站
    ├── 通知
    └── 管理后台
```

首版文档主视图只有“用例库”和“回收站”，不提供“最近打开”。

## 6. 登录与账号

### 6.1 本地账号登录

- 首版仅支持管理员预创建的本地账号，不开放用户注册。
- 登录名在唯一组织内唯一，长度为 3～64 个字符，仅允许 ASCII 字母、数字、点、下划线和连字符，忽略大小写判定冲突。
- 密码长度为 12～128 个字符；服务端不对密码做去空格或 Unicode 归一化，并允许粘贴和密码管理器。
- 管理员创建账号时生成一次性临时密码，仅展示一次，新用户首次登录后必须修改密码才能使用其他功能。
- 首版不提供邮件验证和自助找回密码；用户无法登录时由管理员重置为新的一次性临时密码。
- 登录失败统一提示“账号或密码错误”；同一账号连续失败 5 次后限制尝试 15 分钟，来源地址另设更高的独立限额。
- 账号被禁用、密码被管理员重置或用户修改密码后，撤销该用户的全部现有会话。
- 禁用账号不删除用户，历史文档作者和审计记录继续保留。
- 系统始终至少保留一个有效管理员，不允许禁用最后一个有效管理员。所有管理员都无法登录时，只能由系统维护者通过受控的账号恢复命令重置指定管理员的临时密码。

### 6.2 平台会话

- 账号密码校验成功后建立服务端会话，会话保存在 Redis。
- 浏览器使用 `HttpOnly + Secure Cookie`，并配置适当的 `SameSite`。
- 支持主动退出，由服务端统一控制会话过期和撤销。
- 密码和会话凭证不得返回给无关页面、写入前端持久存储或记录到日志。

## 7. 文件夹与文档管理

### 7.1 文件夹

- 编辑者和管理员可以在“用例库”下创建一级文件夹。
- 首版不支持嵌套文件夹。
- 文件夹名称必填，最多 50 个字符，同级不允许重名。
- 单个工作空间最多 500 个有效一级文件夹。
- 单个文件夹最多包含 1,000 个有效文档。

### 7.2 文档

- 文档名称必填，最多 100 个字符。
- 整个工作空间最多保存 20,000 个文档。
- 文件夹和文档分组展示，文件夹排在文档前面。
- 默认按更新时间倒序，支持按名称排序。
- 编辑者和管理员可以重命名、移动、删除文档或文件夹。
- 首版仅支持单个文档或文件夹操作，不支持批量移动、删除和恢复。

## 8. XMind 导入

### 8.1 文件校验

- 仅接受 `.xmind`，不接受 ZIP、JSON、OPML 或通用附件。
- 单个源文件最大 20 MB。
- 解析后的单个文档最多 20,000 个节点。
- 在整个工作空间内检查同名和相同内容；冲突时阻止该文件导入，不覆盖、不自动改名。
- 文件损坏、格式不兼容或解析失败时不创建文档，并展示可理解的失败原因。
- 不强制导入文件符合某种测试用例模板，允许任意合法 XMind 结构。

### 8.2 多文件导入

- 支持一次选择多个 `.xmind` 文件。
- 默认统一导入当前文件夹，同时允许逐个修改目标文件夹和文档名称。
- 各文件独立处理，一个失败不回滚其他成功文件。
- 最多并行解析 3 个文件，其余进入队列。
- 单用户最多排队 10 个文件，工作空间最多排队 50 个文件。
- 单个解析任务超过 5 分钟自动失败。
- 用户可以取消单个或批量取消尚未开始处理的任务；已开始处理的任务不允许中途取消。
- 关闭或取消导入流程时，保留已经成功的文档，取消未完成任务并清理临时文件。
- 导入前预估整批存储容量，预计超出配额时整批拒绝；运行中因估算偏差导致超额时，仅失败对应文件。

### 8.3 进度与结果

界面分阶段展示上传、解析、持久化和完成状态。结果页包括：

- 总数、成功数和失败数。
- 每个文件的文件名、目标文件夹、处理阶段、结果和失败原因。
- 失败项支持原文件重试、更换本地文件、修改目标名称和目标文件夹。

### 8.4 保存内容与兼容性

成功导入后同时保存：

- 原始 `.xmind` 文件，用于兜底、重新解析和尽力保持导出兼容性。
- 云端标准文档模型，用于在线编辑、搜索、版本管理和实时同步。

必须完整保留主题层级、标题、优先级和基本主题样式；优先保留备注、标签、关系线、图标、基础颜色、字体和图片。不支持的特性可以保留在原始文件中，但可能无法在线编辑。导入成功后需要展示兼容性报告。

## 9. 在线查看与编辑

### 9.1 页面形态

- 桌面端采用左侧树形目录、右侧 XMind 式画布。
- 支持 Chrome 和 Edge 最新两个大版本。
- 首版仅提供浅色模式。
- 移动端提供只读适配，可浏览和搜索，不支持编辑。

### 9.2 编辑能力

- 新增、删除、重命名节点。
- 调整父子层级和拖动排序。
- 设置 P0、P1、P2 优先级。
- 编辑备注、标签、图标、基础颜色和字体。
- 通过文件选择、剪贴板粘贴和拖拽添加图片。
- 自动保存，并保留明确的手动保存入口。

删除节点时连同全部子节点删除，并弹出确认。节点恢复依赖编辑器撤销或最近历史版本，不设置节点级回收站。

### 9.3 图片

- 支持 PNG、JPEG、WebP。
- 单张最大 5 MB。
- 单个云端文档的图片总量最大 50 MB。
- 首版不支持 GIF、SVG 和通用附件。
- 存储配额达到 100% 后禁止新增图片和导入，但仍允许修改文本、节点和标签。

## 10. 编辑锁与实时协作

### 10.1 编辑锁

- 用户点击“开始编辑”后才申请锁，点击“结束编辑”主动释放。
- 编辑锁绑定具体浏览器会话，同一账号的其他设备或浏览器也只能只读。
- 无心跳 15 分钟自动释放。
- 文档被锁定时，展示当前编辑者和最近心跳时间。
- 管理员可以强制释放锁；释放前展示编辑者并二次确认，随后通知原编辑者并将其切换为只读。
- 断网后立即退出编辑并切换为只读，不支持离线继续编辑；网络恢复后需要重新获取编辑锁。

### 10.2 保存与冲突

- 每次成功保存产生完整标准文档快照和单调递增版本号。
- 保存请求必须携带编辑锁凭证和客户端基准版本。
- 服务端版本已变化时拒绝保存，保留本地未保存内容并提示重新加载后处理，不自动覆盖或合并。
- 自动保存失败时保留本地修改、提示失败并提供重试，编辑锁继续保持。
- 导出前必须完成自动保存；保存失败则阻止导出。

### 10.3 只读成员更新

- 保存成功后通过 Socket.IO 推送完整文档快照。
- 客户端仅接受更高版本号，丢弃旧消息。
- 版本跳跃或状态异常时重新拉取服务端最新完整快照。
- WebSocket 断线后自动重连，重连成功重新拉取最新文档，编辑状态不自动恢复。
- 应尽量保留展开状态、滚动位置和选中节点。
- 当前节点被删除时切换到仍存在的父节点、最近祖先或根节点，并提示用户。
- 展示在线用户头像、当前编辑者和最近保存时间。
- 单文档最多 100 人进入实时房间；超出者仍可普通只读访问，但不保证实时在线状态。

## 11. 历史版本

- 5 分钟内的自动保存合并为一个历史版本。
- 手动保存立即生成历史版本。
- 每个文档保留 7 天且最多 30 个版本，以先达到的限制为准。
- 相同图片资源应复用，避免每个版本重复存储。
- 仅编辑者和管理员可以查看及恢复历史版本。
- 恢复前必须取得编辑锁并二次确认。
- 恢复历史版本会生成新的当前版本，恢复前内容先保留为历史版本。
- 恢复后，在线成员立即收到新快照，并尽量保留阅读上下文。

## 12. 搜索

搜索范围：文件夹名称、文档名称、节点标题。

筛选条件：优先级、标签、创建人、更新时间。

规则：

- 只返回当前用户有权查看的数据。
- 结果展示所在文件夹和命中节点路径。
- 点击节点结果直接打开文档，展开左侧路径，在画布中定位并高亮节点。
- 多个命中时先定位第一个，并支持上一个/下一个匹配项。
- 文件夹名和文档名写入成功后立即更新索引；节点索引可以异步更新，但应在短时间内可搜索。

## 13. 回收站

- 删除文档后进入回收站。
- 删除非空文件夹时，文件夹及其中全部文档一起进入回收站；确认框显示影响范围并要求二次确认。
- 恢复文件夹时恢复其文档、归属和排序。
- 恢复出现同名冲突时阻止恢复，不自动改名或覆盖。
- 编辑者和管理员可恢复；只有管理员可永久删除单项或清空回收站。
- 永久删除必须二次确认。
- 回收站内容继续占用存储配额。
- 保留时间由部署配置维护，默认 30 天；到期自动永久删除并释放空间。
- 默认提前 3 天通知管理员即将到期内容。
- 正在查看的文档或文件夹被移入回收站时，提示用户并返回“用例库”或可用父级。

## 14. 导出

- 所有具有阅读权限的成员都可导出 `.xmind`。
- 导出最新成功保存的版本。
- 文件名使用当前文档名称和 `.xmind` 扩展名，本地冲突由浏览器自动追加序号。
- 对在线不支持但原始文件存在的 XMind 特性尽量保留，并提示兼容性限制。

## 15. 通知

平台内通知覆盖：

- 编辑权限申请、通过、拒绝和撤销。
- 文档或文件夹删除、恢复。
- 编辑锁强制释放。
- XMind 导入结果。
- 普通系统告警。

支持单条和全部标记已读，保留最近 90 天。首版不发送外部即时通信消息。严重系统故障额外通过邮件通知系统维护者和管理员。

## 16. 管理后台

首版包括：

- 成员与角色，包括创建账号、重置密码、禁用和恢复账号。
- 权限审批。
- 审计日志。
- 回收站。
- 组织总存储、一级文件夹和文档存储用量。
- 导入失败记录。
- 在线会话。
- 编辑锁管理。
- 基础系统状态：应用、PostgreSQL、Redis、MinIO、导入队列、存储配额和近期故障。

首版不提供单独的系统维护者后台。组织、配额和回收站保留期通过部署配置或受控数据库操作维护；首个管理员必须由幂等的一次性初始化命令创建。

## 17. 审计

必须记录：登录成功/失败、退出、账号创建、密码修改/重置、账号禁用/恢复、导入、编辑锁获取/释放/强制释放、保存、历史恢复、重命名、移动、删除、恢复、永久删除、权限申请、审批、拒绝和撤销。

日志至少包含用户、操作类型、目标对象、时间、结果、请求追踪 ID 和必要版本信息。只有管理员可查看全部审计日志。管理员只能按时间范围清理，不能无条件一键清空；清理操作本身也必须记录。普通用户不能删除审计日志。

## 18. 容量限制

| 项目 | 限制 |
|---|---:|
| 导入 `.xmind` | 单文件 20 MB |
| 单文档节点 | 20,000 |
| 在线图片 | 单张 5 MB |
| 单文档在线图片 | 合计 50 MB |
| 工作空间一级文件夹 | 500 |
| 单文件夹文档 | 1,000 |
| 工作空间文档 | 20,000 |
| 导入解析并发 | 3 |
| 单用户等待导入 | 10 |
| 工作空间等待导入 | 50 |
| 单任务解析超时 | 5 分钟 |
| 单文档实时房间 | 100 人 |

组织存储达到 80% 发普通预警，95% 发严重预警，100% 禁止新导入和新增图片。回收站内容计入配额。

## 19. 性能验收

- 普通 REST 接口在约定基准负载下 P95 小于 1 秒。
- 搜索 P95 小于 2 秒。
- 保存 P95 小于 2 秒，不含新增图片的客户端上传耗时。
- 5,000 节点文档 3 秒内可操作。
- 20,000 节点极限文档采用渐进或虚拟渲染，5 秒内展示首屏并允许基本操作。
- 性能测试环境应接近生产内网服务器配置。

## 20. 首版验收条件

- Chrome、Edge 最新两个大版本的 P0 流程全部通过。
- 本地账号登录、首次强制改密码、登录限流、默认只读、权限审批与撤销通过验证。
- 使用正常、损坏、旧版、多 Sheet、含图、大文件和不支持特性的 XMind 样本完成导入导出兼容性验证。
- 编辑锁、版本冲突、断网、强制释放和未保存内容保护通过端到端测试。
- 删除、回收站、恢复冲突、永久删除和到期清理通过验证。
- 每个受限接口都完成服务端权限测试。
- 备份完整性校验和完整恢复演练成功，并满足 RPO 24 小时、RTO 4 小时。
- 达到本文件规定的性能指标。
