# Phase 3 验证记录

日期：2026-09-18

## 已完成范围

- XMind 多文件批次预检、20 MB 单文件限制、流式 multipart 上传、SHA-256 和私有 MinIO 临时对象。
- PostgreSQL 持久化 `import_batches`、`import_jobs`、`document_assets`、`export_jobs`，包含状态约束、名称/SHA 并发唯一约束和批次汇总。
- 独立 BullMQ 生产导入队列；Worker 并发为 3，任务截止时间为 5 分钟，使用内部任务 ID/对象键，不接受宿主机路径。
- Worker 安全解压、CloudDocumentV1 转换、原始文件/快照/图片/兼容性报告/审计事务持久化，以及重复投递和重试幂等处理。
- Socket.IO `/workspace` 批次订阅鉴权、REST 状态回补、取消/重试 API、Admin 失败列表和 Reader/Editor/Admin 导出权限。
- Web 多文件选择、逐文件改名/一级文件夹选择、Socket.IO 进度订阅（断线后 REST 回补）、取消/重试、管理员失败列表和 XMind 导出按钮。
- MinIO 私有 Bucket、`tmp/` 与 `exports/` 24 小时生命周期规则；OpenAPI 与生成客户端已重新生成并校验。

正式在线画布、编辑锁、图片编辑、实时文档快照协作仍属于阶段 4，未在本阶段实现。
