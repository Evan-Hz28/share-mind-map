# Phase 3 XMind Import and Export Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver production-shaped Phase3 XMind import/export: streamed private-object upload, durable import batches/jobs, BullMQ Worker conversion and persistence, progress/cancel/retry, compatibility reports, and authenticated export.

**Architecture:** PostgreSQL remains the source of truth for batches, jobs, documents, snapshots, assets, exports, and terminal errors. MinIO stores private bytes; the API streams uploads and performs authorization/preflight, while the Worker performs XMind parsing/conversion and export. Redis/BullMQ schedules bounded work, and Socket.IO broadcasts rebuildable progress while REST remains authoritative.

**Tech Stack:** NestJS, Express streaming, PostgreSQL/Drizzle SQL migrations, MinIO SDK, Redis/BullMQ, Socket.IO, Vue/Pinia, `@share-mind-map/xmind`, `@share-mind-map/document-model`, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-09-18-phase-3-design.md`

## Global Constraints

- Do not implement Phase4 canvas editing, edit locks, image editing, or realtime document collaboration.
- Accept only `.xmind` files up to 20 MB and enforce ZIP signature, path, compression, entry, uncompressed-size, encryption, and node limits.
- API never parses XMind or accepts arbitrary host paths; Worker receives internal task/object identifiers.
- PostgreSQL is authoritative; Redis/BullMQ and Socket.IO are reconstructible delivery layers.
- MinIO Bucket stays private; every object access is authorized or uses a short-lived server-issued download.
- Every successful import has original bytes, SHA-256, CloudDocumentV1 snapshot, compatibility report, asset references, and audit evidence.
- Preserve `target.md` deletion and untracked `docs/dev/`; do not stage or commit them automatically.
- Use `apply_patch` for source edits and do not create a commit automatically.
